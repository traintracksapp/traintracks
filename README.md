# TrainTracks

A free workout logger and planner that lives in your own GitHub repository.
Log sets on your phone, track weekly goals, let Claude plan your next workout,
and optionally pull in Garmin data. No server, no subscription: GitHub hosts
the app and stores your data.

- **Set it up:** [docs/SETUP.md](docs/SETUP.md) (about 20 minutes)
- **Claude as your coach:** [docs/COACH.md](docs/COACH.md)
- **Garmin:** [docs/GARMIN.md](docs/GARMIN.md)
- **Optional Worker for Claude Code, CoWork and skills:** [docs/WORKER.md](docs/WORKER.md)
- **File formats:** [docs/DATA-FORMAT.md](docs/DATA-FORMAT.md)

Your repository is public, so your data is too. See the trust model in the setup guide.
